# 杨昊霖（组长）个人建议

## 你的核心产出
- 总框架与共同主题句（贯穿开头、中间比较、结尾）
- 两篇关系比较页 + 结论页
- 最终讲稿整合与 Q&A

## 关键建议（结合讲义与智库建议）
- 绝对不要做成“两篇论文串讲”，必须把“共同主题”放在开头和中段。
- 每个成员都要能回答“共同主题/核心结论/最大差异/课程连接”，避免 Q&A 只你能答。
- 用“Question–Method–Result–Contribution”来统一大家的口径和 slides（来自写作讲义）。
- 先要每人交一页 brief，再整合成 PPT；不要一上来就拼 PPT。
- 版式以清晰、学术、少字为第一优先，最终稿优先用 WPS/PPT 协作。

## 你需要抓住的主轴信息（方便你做比较页）
- 论文1：提供可操作的“informed trading 强度”测度（ITI），强调非线性与交互。
- 论文2：量化 latency arbitrage 的频率、速度与成本，揭示速度竞赛的社会代价。
- 共同问题：信息优势如何被交易化；差别在于“强度测量” vs “速度竞争与制度外部性”。

## 你的输出节奏建议
1. 小会先定一句话主线 + 讲述路线图。
2. 要求每人按统一模板交 brief：Research question / Data / Method / Results / Contribution / Limitation / Course link / 1 figure.
3. 你做比较表与转场脚本，再交给张宸铭统一排版。
4. 彩排时重点压缩文字、提升比较与课程连接的比重。
