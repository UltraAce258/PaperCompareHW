## 论文类型
- 实证微观结构：基于 message data 量化 latency arbitrage 竞赛。

## 快速摘要（你可直接用作口径）
- 用交易所 message data 观察“失败者”，定义 latency arbitrage race；
- race 极频繁、极快，约 20% 成交量；
- 虽然单次利润小，但总量巨大，形成“latency arbitrage tax”；
- 市场设计含义：速度竞赛带来显著社会成本。

## 概念指南（讲解重点）
- Latency arbitrage = 基于公共信息的“抢先交易”，核心是速度竞争。
- Message data 包含失败的 IOC/取消指令，可观察“输家”。
- Race 识别的 4 个特征：多人同侧同价、take/cancel 混合、成败并存、同一时间窗口。
- 关键量化：race 频率、时长、利润、税负与成本分解。
