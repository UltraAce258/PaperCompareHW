# 小组整体建议与计划

## 共同目标与主线
- 共同主题：现代电子市场中，信息优势如何转化为交易优势，以及制度/速度如何放大或扭曲这种优势。
- 论文1回答“如何测量信息交易强度”，论文2回答“速度竞赛带来多大成本”。

## 分工产出
- 组长：总框架、关系比较页、结论页、最终讲稿与 Q&A
- 张宸铭：课程概念映射 + PPT 统一模板/排版
- 陳亭羽：论文1主讲内容页与讲稿
- 李妍：论文2主讲内容页与讲稿

## 工作流程（推荐）
1. 30 分钟小会先定一句话主线与转场逻辑。
2. 每人交一页 brief（Research question / Data / Method / Results / Contribution / Limitation / Course link / 1 figure）。
3. 组长做比较页与结论页；张宸铭统一排版与图表风格。
4. 彩排：压缩文字、提升“比较+课程连接”占比。

## Slides 基本规范
- 每张 slide：1 个核心标题 + 3–4 个 bullet + 1 张图表
- 表格只保留关键行/列；图表统一单位与标注
- 统一配色、字体、段落间距

## Q&A 准备
- 每人都要能回答：共同主题、两篇核心结论、最大差异、课程连接点。
- 预设 3–4 个问题：测度有效性、外部性/福利、政策含义、局限性。
